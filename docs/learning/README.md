# Pasta de aprendizagem

Notas de domínio que qualquer pessoa (ou o Claude, numa sessão nova) lê pra
entender **por que** as métricas do dashboard importam — não só o que elas são.

A ideia: separar "como o código funciona" (isso está em `SPEC.md` e `CLAUDE.md`)
de "como o YouTube e o negócio funcionam" (isso está aqui). Quando uma feature
nova entra na fila (curva de retenção, benchmark, funil de vendas), a nota de
aprendizagem correspondente explica o raciocínio antes de virar plano.

Índice:

- `01-como-o-youtube-decide.md` — o que faz um vídeo crescer ou morrer.
- `02-glossario-de-metricas.md` — cada métrica do dashboard, o que mede e as
  armadilhas (fração vs. percentual, top80 vs. média, etc.).

Adicione novas notas numeradas conforme o projeto avança.
